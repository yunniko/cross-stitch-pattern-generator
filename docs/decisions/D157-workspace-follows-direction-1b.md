Date: 2026-09-18 · Goal: G-045 · Status: active (superseded by: —)
Context: four strips sat above the chart, and the settings were split across a top bar, a params dock and an options panel. The Owner chose direction 1b, "Atelier".
Decision: a 64px tool rail, a context bar that changes with the document, the chart in a ruled well, a status bar, and one 360px inspector showing a single pane behind Photo, Chart and Threads tabs. Generate sits in the Photo footer, the exports in the Threads footer. Atelier is the only appearance, because 1b draws no light variant.
Rejected: keeping the stacked bars; inventing a light palette nobody designed; following 1b where it drops working controls — Algorithm, author name, A4 overlap, photo-only and Rotate left are kept and placed (Owner), and the colour editor stays inline rather than becoming a pane.
Consequence: the file actions live behind the mark on the rail, since 1b draws them only on its first run. The navigator leaves the interface but stays an off-screen raster three specs read.
