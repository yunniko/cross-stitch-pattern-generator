# D250 · The canvas cloth is the well's CSS background, one tile per cell
Date: 2026-09-30 · Goal: G-077 M1 · Status: active (superseded by: —)
Context: the Owner wants a canvas texture over the whole viewer (not only the chart frame), Stitched view only, multiplied with the canvas colour, zooming with the cells.
Decision: the scrolling well gets the tile as a `local` CSS background with `multiply` blend, sized `cells × cellSize` and offset to the chart's first cell; the chart canvas clears its ground instead of filling it.
Force: requirement — Owner spec: whole viewer, multiply with the colour, scale tied to cell size (counted canvas later).
Rejected: painting the cloth into the chart canvas (it is only viewport-sized and would need repainting on every scroll); one stretched image (the weave would not follow the cells).
Consequence: a texture is a catalog entry (`cells` = cells per tile) and a light greyscale tile; the origin is re-measured on zoom and resize, never on scroll. Textures are generated by `scripts/generate-canvas-textures.mjs`, so they carry no licence.
Evidence: tests/e2e/canvas-texture.spec.ts; tests/unit/canvas-cloth.spec.ts
