# Exploratory QA, 2026-10-04, third pass (G-092)

**Mode and scope:** scoped pass on what G-092 changed: how the pointer and the keys reach the tool in hand. Local production
build with the Rust engine, on the uncommitted G-092 work. A throwaway Playwright probe drove the interface and printed what
it saw. G-092 is a refactor with no intended change of behaviour, so the question was "is anything different", and the
whole automated suite is the larger part of the answer.

## Findings

| # | Severity | Finding | Outcome |
|---|---|---|---|
| 1 | test defect | A spec's harness handed the renderer a tool called "highlight", which stopped existing at D158. The registry refuses a tool it does not hold, by name, so 14 parity cases failed | Fixed in the spec: the live scene is drawn with the brush in hand. The refusal is the registry working as intended |
| 2 | usability (old) | After Add in the Text settings, pressing Enter both applies the lettering and adds it again, because the Add control still has the focus | Left for triage; it predates this goal and is the same before and after |

## What held

Every tool's key chooses it (B, F, L, R, O, G, K, J, Q, C) and other letters do nothing. A rectangle half drawn when
another tool's key is pressed is dropped and nothing is drawn. A brush stroke in progress when another tool's key is pressed
is still committed, as one undo step. A piece in hand survives a swap between Select and Lasso and is applied by choosing
another tool. Escape puts down a backstitch line in hand; Backspace deletes it and does not leave the page. In a
looking-only view no tool changes the chart or takes a piece, and Zoom still zooms. Holding Space borrows Pan from Brush,
Rectangle, Backstitch, Backstitch edit, Lasso and Crop and returns each. Lettering arrives as a piece with the Select tool
in hand. No page or console error occurred.

**The proof asked for by the goal:** a temporary eraser tool was added as one module file and one registry line (plus its
import), with no other file touched. It appeared in the tool list, took its key, showed its outline, erased a stitch and was
undone (1,550 stitches, one erased, undo restored). It was then removed; it is not shipped.

## Coverage

**Exercised:** tool keys, tool changes in the middle of two gestures, piece hand-over, Escape and Backspace with backstitch,
the looking-only gate, Space-pan from six tools, lettering.

**Not exercised by the probe:** double-press fill, backstitch runs with Ctrl, Move, the crop frame's keys, and every tool's
own drawing: these are covered by the existing suite (547 cases), which passed unchanged apart from finding 1. Not checked:
the live site until after deploy; touch input.
