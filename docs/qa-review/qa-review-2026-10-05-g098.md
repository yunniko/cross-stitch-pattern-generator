# Exploratory QA, 2026-10-05 (G-098)

**Mode and scope:** scoped pass on what G-098 moved out of the editor shell: the ways a chart arrives and leaves, the
confirmation, the messages, the autosave and restore, what a new chart resets, the photo-slider rule, the name being
typed, and the editor's own commands. Local production build with the Rust engine, on the uncommitted M3 work. A throwaway
Playwright probe drove the interface. The goal intends no change of behaviour, so the question was "is anything different",
and where a result looked different the same probe was run against the live site, which still had the code from before.

## Findings

| # | Severity | Finding | Outcome |
|---|---|---|---|
| 1 | usability (old) | The colour count a new photo is given comes from a recommendation that can arrive seconds after the photo. If the person has already changed the count by then, the recommendation overwrites their choice. Seen locally (the count went 16, then 8 by itself); the same probe on the live site, with the old code, behaves the same, the recommendation only arriving sooner there | Left for triage; unchanged by this goal |
| 2 | test defect (old) | `photo-sliders.spec.ts`, "each slider moves the thing it names", reads the preview once without waiting for it to be painted, and failed once in a full run on that read. 36 of 36 when run alone | Left for G-096 (the development loop), where the specs are reworked |
| 3 | test flake (old) | `backstitch-draw.spec.ts`, "letting go of Ctrl ends a chain", failed once in a full run during M2 and passed on retry; 60 of 60 alone | Recorded; load, as far as it can be told |

## What held

**Ways in, with a chart open.** An empty grid asks first; Keep editing keeps the chart; "Export, then start new" downloads
the editable file and starts the blank chart, where undo is unavailable. "Choose a photo" from the command list asks first,
then opens the chooser; the photo loads with no chart, and generating makes one. Pixel art that cannot be read keeps the
chart and returns to the start screen. A file that is not JSON shows its message and keeps the chart; a good file opened
after it clears the message. An OXS file opens with its note.

**Reload and regenerate.** After an edit and a reload the saved file is the same bytes, the symmetry axis is still on,
Isolate is off. Regenerate keeps the zoom, the view, the symmetry and Isolate and shows the thread list, which is what its
row of the replace table says.

**Rules that moved.** The name being typed is not an undo step until it is committed, and undo puts the earlier name back
in the entry. No page error in any of it; the one console error is the app's own log line for the file that was meant to
fail.

## Coverage

**Exercised:** the above. The lit-thread rule, the fabric rule and when each of the editor's 38 commands can run are
covered by the 21 new unit tests rather than by the probe; lighting threads, Space-pan and the keys are also covered by
existing browser cases, which passed.

**Not exercised:** restoring a damaged autosave (existing unit and browser cases cover it); a photo that cannot be read;
the message of refused pixel art (the probe's own locator did not find it; the existing pixel-art cases assert it and
passed). The photo-slider rule was not probed conclusively: the probe moved the colour count, not a photo slider, which is
how finding 1 was seen; the rule's own browser cases (`photo-sliders*.spec.ts`) passed. The live site is checked after
deploy.
