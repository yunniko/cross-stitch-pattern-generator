## What held

- **Names.** Empty is refused by the field; spaces alone, a taken name, a 60-character name, a name with a script tag and one
  with Cyrillic and an emoji are each refused or kept as they should be, with the reason shown.
- **Sequencing.** A double press on Make a set makes one set. Six rapid presses on one feature's states ending On leave no
  row; a group set Hidden then On leaves no rows. A nonsense user id is a 404. The change log shows each change with the
  admin's email.
- **Access.** A visitor is sent to the sign-in and a signed-in reader to the editor, for both pages (spec).
- **The states, end to end** (`tests/e2e/features.spec.ts`, `admin-features.spec.ts`): a visitor gets the site's; a locked
  tool is greyed with its note and its key does nothing; a hidden export kind, brand and tool are absent; the server refuses
  a generation asking for Vivid, Cosmo or Atkinson and an export of A4 pages with 403 and the name, and lets the
  asks-for-nothing values through; a person's state wins over the tier's set, which wins over the site's, an explicit On
  lifting a lock; a stored hidden brand is read as the full range.
- No page error in any probe.
