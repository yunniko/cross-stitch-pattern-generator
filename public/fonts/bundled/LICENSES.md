# Bundled fonts

Every font here is licensed under the **SIL Open Font License, Version 1.1** (https://openfontlicense.org), which allows
bundling and use in a product; the licence text sits beside each font as `OFL.txt`. None is modified or renamed. They were taken
on 2026-10-01 from the Google Fonts repository (https://github.com/google/fonts, folder `ofl/`), and are served from this
site only: no page asks Google or anyone else for them.
