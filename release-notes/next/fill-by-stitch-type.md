Fill now keeps to the stitch type it is pressed on: filling whole stitches no longer spreads into half stitches of the same colour. Two new Fill options: **Color only** changes just the colour, keeps each stitch's type and fills across types; **Diagonal neighbours** can be set to **Edges only**, so stitches touching only at a corner are left out. The Brush's double press no longer fills a region, and its preference is gone.
