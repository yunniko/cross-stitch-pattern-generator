Charts can have layers. Under Edit, the Layers list adds, hides, renames, reorders, merges and deletes them. Drag a layer onto another's Merge box to merge the two. Drawing tools work on the active layer. Backstitch stays above every layer. The thread counts, every export and the editable file follow what is shown: hidden layers are not counted, but the editable file keeps them.
