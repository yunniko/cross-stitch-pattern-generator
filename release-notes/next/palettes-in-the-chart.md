Palettes can now be saved and loaded on the Edit page too. A loaded palette can be appended, adding only the colours your chart doesn't have yet, or it can replace the chart's palette: each colour moves to the same thread in the new palette, or else to the closest-looking colour. Palette files now keep each colour's name and its thread system and number, and older palette files still open. While setting up a palette you can name each colour and type its thread, and switching the thread system no longer clears your colours.
