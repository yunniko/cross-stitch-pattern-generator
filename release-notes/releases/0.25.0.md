## New

- Signed in, your saved palettes are now kept with your account, in one list on the photo page and the Edit page, each colour with its name and thread. Palettes this browser kept before are offered once to move in. Signed out, a palette saves as a file.
- Palettes can now be saved and loaded on the Edit page too. A loaded palette can be appended, adding only the colours your chart doesn't have yet, or it can replace the chart's palette: each colour moves to the same thread in the new palette, or else to the closest-looking colour. Palette files now keep each colour's name and its thread system and number, and older palette files still open. While setting up a palette you can name each colour and type its thread, and switching the thread system no longer clears your colours.
- Each colour's thread system and number can be typed in the colour editor, including numbers our thread lists don't have. Typing a number never changes the colour, and changing the colour keeps its number.

## Changed

- A chart is no longer tied to one thread system: any colour can be a DMC, Cosmo or Anchor thread, or a colour of your own, whatever the chart was generated in. Stamps can now go into any chart.
- Printed keys now have the same columns for every chart. The A4 thread table, the colour key and the Pattern Keeper PDF show each colour's thread system and number in their own columns, left blank for a colour of your own, and the details name every thread system the chart uses. The full chart picture's legend says the same on one line, for example "Anchor 403 - Black". OXS files now carry numbers you typed yourself.
