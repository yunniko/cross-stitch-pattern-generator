## New

- Layers can be locked. Press the lock on a layer's row in the Layers list: the layer stays visible, but it can't be drawn on, renamed, merged or deleted until you unlock it. Cropping, moving the whole design and changing colours still apply to it, so it stays in line with the other layers. The lock is saved with the chart.

## Fixed

- Every try can be chosen again. Generating the same chart with the same settings no longer adds a copy: the try you already have is marked instead. The tries strip no longer has a "Continue in Edit" box beside it that covered the last try when there were many; use the Edit workspace above to go on editing.
