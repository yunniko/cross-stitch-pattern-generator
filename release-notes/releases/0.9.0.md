## New

- A new **Magic wand** tool (W) selects the whole area of one colour with one click, using the same **Diagonal neighbours** and **Color only** choices as Fill (set separately). Clicking a backstitch line selects every line of that colour. It works with **Select +**, **Select −** and **Invert selection**, like Select and Lasso.
- Select and Lasso have three modes: **Select** replaces the selection, **Select +** adds to it and **Select −** takes away from it. A new **Invert selection** button selects everything else, backstitch included. The selection's size no longer shows in the bar.

## Changed

- Select, Lasso and the Magic wand now have a **Selection** tab in the right panel holding every selection action, grouped: Select, Copy and paste, Paint, Flip and turn, Chart and Finish. The top bar keeps the selection mode (Select, Select +, Select −) and **Apply here** and **Cancel**, so nothing is cut off at any window width.
- Sign-in is safer: after too many attempts in a short time it asks you to wait a few minutes, and you stay signed in for up to a week before signing in again. A file exported from a photo whose name holds accented letters (such as "Kočka") now downloads under that name.
